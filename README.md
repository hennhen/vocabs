# Vocabs

A Home Screen web app (PWA) for building an advanced English vocabulary with spaced repetition,
plus Traditional Chinese (繁體) translations as a bridge. See [PLAN.md](PLAN.md).

```bash
npm install
npm run dev     # dev server (use --host to open it from a phone on the same network)
npm test        # unit tests
npm run build   # production build in dist/
```
